## 修复的两个边界问题

### 重新接取后的达标成绩

原先任务只读取历史最高分 storyBest。玩家放弃后重新接受任务，即使新局达到基础等级，只要没超过旧最高分，也可能无法完成。现在保留最高分供历史展示，并以 storyLatest 记录最近一次合格剧情局；任务优先使用接受之后、未列入 baseline 的新记录。失败、年度与练习局不覆盖该记录。

### 计时器取消正常收报

LightsEventScreen 的收报 effect 依赖整个 run 对象，活动计时每 250 ms 更新该对象，而正常收报开始延迟为 260 ms。旧逻辑会清除待开始的收报；已开始时也可能丢失播放完成后的阶段推进。改为用局 ID、阶段、回合、恢复次数与当前呼叫队列作为稳定依赖，并以 ref 取得该次播放快照。设置暂停、失焦取消和 AGN 重发仍各自触发正确的播放生命周期。
