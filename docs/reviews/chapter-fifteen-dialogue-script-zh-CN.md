## 事实绑定与收尾边界

- {player} 来自当前存档；{peer}、{rst} 来自经过校验的实际日志，不使用示意台站名。
- {ending} 对应封存时实际选择的目标。五段是未来打算，不声称已经获得地区、人物、野外、公共服务或竞赛成就。
- 公共服务段明确为游戏内模拟，不指示用户操作现实应急网络。
- 五选项没有默认选中；封存前可改，选择和对应通联 ID 一同保存。
- 封存不额外发钱。章节奖励为 2000 资金、8 科技点，一次领取；成就奖励另计。
- 开放电台中的当前目标可在通关后调整，最初目标和第一页记录不随之改变。
- 继续复用现有第十五章场景和插画，没有新增人像身份、配音或背景音效。
