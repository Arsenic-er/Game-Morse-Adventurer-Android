# 第二章中文台词审阅稿

本稿从正式游戏的 chapterTwoStoryText.js 提取。演出使用既有第二章场景、人物图和插图；电台内的实际发报仍由通联系统产生。

## 叙事边界

- 前三幕是接任务后的准备；后两幕只读取已保存、已结算且匹配任务事件的 SIM3RA 通联。
- 必须存在成功的 AGN K 重发记录。旁白不冒充电台原文，不提前说出领奖后才解锁的名字。
- {player} 取当前存档呼号；{peer} 取本次合格通联呼号。时间、双方 RST 和频率在任务记录中读取真实值。
- 按 humanizer-zh 的检查原则，把描写落在挪台灯、核对呼号、记录 RST 等动作上；不把旧日志的空白擅自补成已发生的故事。

## 1. 灯往这边挪一点

演出节点：paper；素材：scene。

你把旧日志往台灯下挪了一点。纸边已经卷了，SIM3RA 被铅笔圈了起来。

你用手指压住翘起的页角。呼号后面留着一块空白，不知道当时为什么停在这里。

## 2. 先把呼号抄下来

演出节点：margin；素材：scene。

你翻了前后两页，也没找到补上的记录。还是先把能看清的几个字母记下来。

SIM3RA。你照着旧纸又核对一遍，然后把新日志放到电键旁边。

## 3. 请对方再发一遍

演出节点：call；素材：illustration。

你在新日志上写下自己的呼号：{player}。戴好耳机，准备找一找 SIM3RA。

这次要练习请求重发。发出 AGN K 后，再听一遍对方的内容，核对好了再往下发。

## 4. 这次抄全了

演出节点：answer；素材：portrait。

通联结束后，你把新记录里的呼号和旧字放在一起看。{peer}，一个字母也没差。

刚才请求重发的时候，你还担心会耽误对方。现在至少不用对着那几个字母猜了。

## 5. 新的一行

演出节点：log；素材：scene。

你写下这次通联的时间，核对双方的 RST。旧记录里没写清楚的地方仍然留着，免得把两次通联混成一次。

你扣上笔帽，又看了一眼 {peer}。下次再遇见这个呼号，就不用先翻那张旧纸了。

## 任务提示

联系 SIM3RA，在通联中实际发送一次 AGN K，请对方重发，再完成并保存通联。没收到回应时可以重试，不会自动补出一条通联。

任务奖励只领取一次；通联收入已在保存日志时结算。
